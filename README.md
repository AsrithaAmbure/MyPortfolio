## ⚡ How to Push to GitHub & Enable GitHub Pages

Since Git has already been initialized in this project directory with remote `https://github.com/AsrithaAmbure/MyPortfolio.git`, follow these simple commands in your terminal to publish:

### 1. Push Code to GitHub
```bash
cd "C:\Users\Charitha.A\Desktop\MyPortfolio"
git add .
git commit -m "feat: initial placement portfolio build"
git branch -M main
git push -u origin main
```

### 2. Enable GitHub Pages (Free Hosting)
1. Go to your GitHub Repository: [https://github.com/AsrithaAmbure/MyPortfolio](https://github.com/AsrithaAmbure/MyPortfolio)
2. Click on **Settings** (top navbar of the repository).
3. On the left sidebar, click on **Pages**.
4. Under **Build and deployment** -> **Branch**, select `main` and `/ (root)`, then click **Save**.
5. In 1-2 minutes, your live portfolio will be live at:
   `https://asrithaambure.github.io/MyPortfolio/`
